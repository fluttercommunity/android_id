# android_id_example

Shows the Android ID and handles missing registration or lookup failures. Other platforms display an unavailable ID.

Flutter 3.47 or newer. Run on Android API 24 or newer to retrieve an ID.

For Android tooling and platform requirements, see the [package README](../README.md).

From this directory, select a compatible Flutter SDK with FVM, then run:

```sh
fvm flutter pub get
fvm flutter run -d <device-id>
```
